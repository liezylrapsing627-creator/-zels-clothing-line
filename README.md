# Zel's Clothing Line

A responsive, one-page clothing boutique website built with plain HTML, CSS, and JavaScript. No build step or framework required.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

Optional: use the VS Code Live Server extension for local preview.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish your site.

## Customize

- Edit the store text, categories, phone number, and hours in `index.html`.
- Adjust colors, spacing, and responsive styling in `style.css`.
- Update navigation behavior in `script.js`.

## Notes

- The contact number is linked with `tel:` so mobile visitors can tap to call.
- Fashion photography is loaded from Unsplash over the internet, and the heading fonts load from Google Fonts. An internet connection is needed for those remote assets.
- Store hours are displayed as every day, 8:00 AM–8:00 PM.
